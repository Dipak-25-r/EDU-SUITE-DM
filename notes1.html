તારીખ:

૧. ગણ (Sets)

સ્પષ્ટ ગુજરાતી સમજૂતી

ગણ એ સુનિશ્ચિત અને સુવ્યાખ્યાયિત વસ્તુઓના સંગ્રહને કહેવાય છે. ગણના ઘટકોને છગડિયા કૌંસમાં { } દર્શાવવામાં આવે છે. ઉદાહરણ તરીકે, પ્રાકૃતિક સંખ્યાઓનો ગણ $\mathbb{N} = \{1, 2, 3, \ldots\}$

મહત્વના સૂત્રો (Formulas)

  • **ગણ A અને B નો યોગ ગણ:** $A \cup B = \{x : x \in A \text{ અથવા } x \in B\}$
  • **ગણ A અને B નો છેદ ગણ:** $A \cap B = \{x : x \in A \text{ અને } x \in B\}$
  • **યોગ ગણ માટેનું સૂત્ર:** $n(A \cup B) = n(A) + n(B) - n(A \cap B)$

સોલ્વ કરેલ ઉદાહરણો (Solved Examples)

ઉદાહરણ ૧: જો $A = \{1, 2, 3\}$ અને $B = \{3, 4, 5\}$ હોય, તો $A \cup B$ અને $A \cap B$ શોધો.

ઉકેલ:

  1. $A \cup B = \{1, 2, 3, 4, 5\}$
  2. $A \cap B = \{3\}$

૨. સંબંધો અને વિધેયો (Relations & Functions)

સ્પષ્ટ ગુજરાતી સમજૂતી

બે અરિક્ત ગણ A અને B માટે, ગણ A થી B પરનો સંબંધ એ કાર્તેઝીય ગુણાકાર $A \times B$ નો ઉપગણ છે. વિધેય એ એક ખાસ પ્રકારનો સંબંધ છે જેમાં A ના પ્રત્યેક ઘટક B ના અનન્ય ઘટક સાથે જોડાયેલો હોય છે.

મહત્વના સૂત્રો (Formulas)

  • **સંબંધ:** $R \subseteq A \times B$
  • **વિધેય:** $f(x) = y$
  • **સંબંધોની કુલ સંખ્યા:** જો $n(A)=p$ અને $n(B)=q$, તો સંબંધોની સંખ્યા $2^{pq}$ છે.

૩. ત્રિકોણમિતિ (Trigonometry)

સ્પષ્ટ ગુજરાતી સમજૂતી

ત્રિકોણમિતિ એ ત્રિકોણની બાજુઓ અને ખૂણાઓ વચ્ચેના સંબંધનો અભ્યાસ છે. રેડિયન અને ડિગ્રી માપ ખૂણાઓ માપવા માટે વપરાય છે. $\sin$, $\cos$, $\tan$ મુખ્ય ત્રિકોણમિતિય વિધેયો છે.

મહત્વના સૂત્રો (Formulas)

  • **પાયથાગોરસના નિત્યસમ:** $\sin^2 x + \cos^2 x = 1$
  • **સરવાળાના સૂત્રો:** $\sin(x+y) = \sin x \cos y + \cos x \sin y$
  • **ડબલ એંગલ સૂત્રો:** $\cos(2x) = \cos^2 x - \sin^2 x$

૪. સુરેખ અસમાનતાઓ (Linear Inequality)

સ્પષ્ટ ગુજરાતી સમજૂતી

સુરેખ અસમાનતામાં, સમીકરણના બદલે $<,>, \le, \ge$ ચિહ્નોનો ઉપયોગ થાય છે. અસમાનતાનો ઉકેલ સામાન્ય રીતે સંખ્યા રેખા પર અથવા સમતલમાં અર્ધ-સમતલ તરીકે દર્શાવવામાં આવે છે.

મહત્વના સૂત્રો (Formulas)

  • **સામાન્ય સ્વરૂપ:** $ax + by < c$
  • **નિયમ:** અસમાનતાના બંને બાજુએ ઋણ સંખ્યા વડે ગુણવાથી કે ભાગવાથી અસમાનતાનું ચિહ્ન બદલાય છે.

૫. ક્રમચય અને સંચય (Permutations & Combinations)

સ્પષ્ટ ગુજરાતી સમજૂતી

ક્રમચય એ વસ્તુઓની ગોઠવણી છે જ્યાં **ક્રમ મહત્વનો** છે. સંચય એ વસ્તુઓની પસંદગી છે જ્યાં **ક્રમ મહત્વનો નથી**.

મહત્વના સૂત્રો (Formulas)

  • **ક્રમચય:** $P(n, r) = \frac{n!}{(n-r)!}$
  • **સંચય:** $C(n, r) = \frac{n!}{r!(n-r)!}$
  • **સંબંધ:** $P(n, r) = r! \cdot C(n, r)$

૬. દ્વિપદી પ્રમેય (Binomial Theorem)

સ્પષ્ટ ગુજરાતી સમજૂતી

દ્વિપદી પ્રમેય $(a+b)^n$ ના ઘાતનું વિસ્તરણ કરવા માટેનું સૂત્ર આપે છે. વિસ્તરણમાં $(n+1)$ પદો હોય છે.

મહત્વના સૂત્રો (Formulas)

  • **દ્વિપદી પ્રમેય:** $(a+b)^n = \sum_{k=0}^{n} C(n, k) a^{n-k} b^k$
  • **સામાન્ય પદ:** $T_{k+1} = C(n, k) a^{n-k} b^k$

૭. સુરેખાઓ (Straight Lines)

સ્પષ્ટ ગુજરાતી સમજૂતી

સુરેખા એ એક પરિમાણીય અનંત લંબાઈનો આકાર છે. તેનો ઢાળ અને વિવિધ સ્વરૂપોમાં સમીકરણો શોધી શકાય છે.

મહત્વના સૂત્રો (Formulas)

  • **ઢાળ (Slope):** $m = \frac{y_2 - y_1}{x_2 - x_1}$
  • **ઢાળ-અંત:ખંડ સ્વરૂપ:** $y = mx + c$
  • **બિંદુ-ઢાળ સ્વરૂપ:** $y - y_1 = m(x - x_1)$

૮. શંકુચ્છેદ (Conic Sections)

સ્પષ્ટ ગુજરાતી સમજૂતી

શંકુચ્છેદ એ શંકુ અને સમતલના છેદથી મળતા વક્રો છે: વર્તુળ, પરવલય, ઉપવલય અને અતિવલય. પ્રત્યેકનું પોતાનું પ્રમાણભૂત સમીકરણ હોય છે.

મહત્વના સૂત્રો (Formulas)

  • **વર્તુળ:** $x^2 + y^2 = r^2$
  • **પરવલય:** $y^2 = 4ax$
  • **ઉપવલય:** $\frac{x^2}{a^2} + \frac{y^2}{b^2} = 1$

૯. લિમિટ્સ અને વિકલનો (Limits & Derivatives)

સ્પષ્ટ ગુજરાતી સમજૂતી

લિમિટ્સ (સીમાઓ) એ વિધેયના મૂલ્યને નિર્ધારિત કરે છે જ્યારે ચલ કોઈ ચોક્કસ મૂલ્યની નજીક પહોંચે છે. વિકલન (Derivative) એ ફેરફારનો તાત્કાલિક દર છે.

મહત્વના સૂત્રો (Formulas)

  • **વિકલનની વ્યાખ્યા:** $f'(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$
  • **ઘાત નિયમ:** $\frac{d}{dx} (x^n) = nx^{n-1}$
  • **ગુણાકાર નિયમ:** $(uv)' = u'v + uv'$
