GSEB Class 12 Self Learning

નિશ્ચાયક (Determinants): મુખ્ય વ્યાખ્યાઓ અને સૂત્રો

પ્રત્યેક $n$ કક્ષાવાળા ચોરસ શ્રેણિક $A = [a_{ij}]$ ને એક વાસ્તવિક અથવા સંકર સંખ્યા સાથે સાંકળી શકીએ છીએ, જેને નિશ્ચાયક કહે છે.

૧. નિશ્ચાયકની કક્ષા અને વિસ્તરણ

  • ૧ કક્ષાવાળો શ્રેણિક: $\det A = a$
  • ૨ કક્ષાવાળો શ્રેણિક: $\det(A) = \begin{vmatrix} a_{11} & a_{12} \\ a_{21} & a_{22} \end{vmatrix} = a_{11}a_{22} - a_{21}a_{12}$
  • મહત્વનો ગુણધર્મ: જો $A$ અને $B$ એ $n$ કક્ષાવાળા ચોરસ શ્રેણિક હોય અને $A = kB$ હોય, તો $|A| = k^n |B|$ થાય.

૨. ઉપનિશ્ચાયક અને સહઅવયવ (Minors & Cofactors)

ઉપનિશ્ચાયક ($M_{ij}$): $a_{ij}$ વાળી હાર અને સ્તંભ દૂર કરવાથી મળતો $(n-1)$ કક્ષાવાળો નિશ્ચાયક.
સહઅવયવ ($A_{ij}$): $A_{ij} = (-1)^{i+j} M_{ij}$
૩ કક્ષાવાળા વિસંમિત શ્રેણિકના નિશ્ਚાયકનું મૂલ્ય શૂન્ય ($|A|_{3 \times 3} = 0$) હોય છે.

૩. સહઅવયવજ શ્રેણિકનાં ગુણધર્મો

1. $A(\text{adj } A) = |A|I_n$
2. $\text{adj}(A^T) = [\text{adj}(A)]^T$
3. $\text{adj}(KA) = K^{n-1}\text{adj}(A)$
4. $\text{adj}(AB) = (\text{adj } B)(\text{adj } A)$
5. $|\text{adj } A| = |A|^{n-1}$
6. $|\text{adj}(\text{adj } A)| = |A|^{(n-1)^2}$

૪. વ્યસ્ત શ્રેણિક અને સુરેખ સમીકરણો

વ્યસ્ત શ્રેણિક: જો $|A| \neq 0$ (સામાન્ય શ્રેણિક), તો $A^{-1} = \frac{1}{|A|} \text{adj}(A)$
સમીકરણ સંહતિનો ઉકેલ: $AX = B \implies X = A^{-1}B$ (જો $|A| \neq 0$ હોય તો અનન્ય ઉકેલ મળે).

૨ $\times$ ૨ અને ૩ $\times$ ૩ નિશ્ચાયક કેલ્ક્યુલેટર લેબ

નીચે ઘટકો દાખલ કરો અને ત્વરિત નિશ્ચાયકનું મૂલ્ય ($|A|$) મેળવો.

રેખાનું સમીકરણ ($A$ અને $B$ માંથી પસાર થતી):

સમીકરણ: $y - y_1 = \frac{y_2 - y_1}{x_2 - x_1} (x - x_1)$

શ્રેણિકના વ્યસ્તના ઉપયોગથી સુરેખ સમીકરણોની સંહતિનો ઉકેલ

સુસંગત (Consistent) અને અસંગત (Inconsistent) સંહતિની ચકાસણી.

સુરેખ સમીકરણો:

$a_1x + b_1y + c_1z = d_1$
$a_2x + b_2y + c_2z = d_2$
$a_3x + b_3y + c_3z = d_3$

આપેલ સમીકરણોને $AX = B$ સ્વરૂપમાં લખી $X = A^{-1}B$ દ્વારા ઉકેલ મેળવાય છે.

મહત્વના નિયમો (Rules):

  • જો $|A| \neq 0$: સંહતિ સુસંગત છે અને અનન્ય ઉકેલ ($X = A^{-1}B$) મળે છે.
  • જો $|A| = 0$ અને $(\text{adj } A)B \neq O$: ઉકેલનું અસ્તિત્વ નથી અને સંહતિ અસંગત છે.
  • જો $|A| = 0$ અને $(\text{adj } A)B = O$: અનંત ઉકેલ અથવા ઉકેલ નથી.
