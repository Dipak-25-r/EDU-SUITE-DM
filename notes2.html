૧. ગણ (Sets)

ગણ એ સુનિશ્ચિત અને સુવ્યાખ્યાયિત વસ્તુઓનો સમૂહ છે. ગણનું નિરૂપણ મુખ્યત્વે બે રીતે થાય છે: યાદીની રીત અને ગુણધર્મની રીત.

મહત્વના સૂત્રો

બૈજિક ગણનો સરવાળો: $$\vert A \cup B \vert = \vert A \vert + \vert B \vert - \vert A \cap B \vert$$ પૂરક ગણ: $$\text{A' = U - A}$$

ઉકેલાયેલું ઉદાહરણ

પ્રશ્ન:

જો A = {1, 2, 3, 4} અને B = {3, 4, 5, 6} હોય, તો A $\cup$ B અને A $\cap$ B શોધો.

ઉકેલના પગલાં:

  • A $\cup$ B (યોગ ગણ) માં A અથવા B ના બધા સભ્યો આવે.
  • $$A \cup B = \{1, 2, 3, 4, 5, 6\}$$
  • A $\cap$ B (છેદ ગણ) માં A અને B બંનેના સામાન્ય સભ્યો આવે.
  • $$A \cap B = \{3, 4\}$$

ચિત્રાત્મક રજૂઆત

પ્રેક્ટિસ પ્રશ્નો

  • જો $U = \{1, 2, ..., 10\}$ અને $A = \{2, 4, 6, 8, 10\}$ હોય, તો $A'$ શોધો.
  • ગણ $\{x : x \in N \text{ અને } x^2 < 16\}$ ને યાદીની રીતે લખો.

૨. સંબંધો અને વિધેયો (Relations & Functions)

બે અરિક્ત ગણ A અને B માટે, A થી B પરનો સંબંધ એ કાર્ટેઝિયન ગુણાકાર $A \times B$ નો ઉપગણ છે. વિધેય એ એક ખાસ પ્રકારનો સંબંધ છે જ્યાં પ્રત્યેક ઘટક એક અને માત્ર એક જ પ્રતિબિંબ ધરાવે છે.

મહત્વના સૂત્રો

વિધેયની વ્યાખ્યા: $$\text{A થી B પરનું વિધેય } f: A \to B \text{ હોય, તો પ્રત્યેક } x \in A \text{ માટે અનન્ય } y \in B \text{ મળે છે.}$$ માનાંક વિધેય: $$f(x) = |x| = \begin{cases} x, & \text{જો } x \ge 0 \\ -x, & \text{જો } x < 0 \end{cases}$$

ઉકેલાયેલું ઉદાહરણ

પ્રશ્ન:

જો $f(x) = x^2 + 2$ હોય, તો $f(3)$ અને $f(-1)$ શોધો.

ઉકેલના પગલાં:

  • $x=3$ મૂકતાં: $f(3) = (3)^2 + 2 = 9 + 2 = 11$
  • $x=-1$ મૂકતાં: $f(-1) = (-1)^2 + 2 = 1 + 2 = 3$

૩. ત્રિકોણમિતિ (Trigonometry)

ત્રિકોણમિતિ એ ત્રિકોણની બાજુઓ અને ખૂણાઓ વચ્ચેના સંબંધનો અભ્યાસ છે. રેડિયન અને અંશ એ ખૂણાના માપના એકમો છે.

મહત્વના સૂત્રો

પાયથાગોરસ ઓળખ: $$\sin^2\theta + \cos^2\theta = 1$$ સરવાળાના સૂત્રો: $$\cos(A+B) = \cos A \cos B - \sin A \sin B$$

પ્રેક્ટિસ પ્રશ્નો

  • $\cos 15^{\circ}$ નું મૂલ્ય શોધો.
  • જો $\tan x = -\frac{4}{3}$ હોય અને $x$ બીજા ચરણમાં હોય, તો $\sin x$ અને $\cos x$ શોધો.

૪. સુરેખ અસમતાઓ (Linear Inequality)

અસમતા એ એક ગાણિતિક વિધાન છે જે બે મૂલ્યો સમાન નથી તે દર્શાવે છે. સુરેખ અસમતાઓનું નિરાકરણ રેખાકૃતિ દ્વારા પણ થઈ શકે છે.

ઉકેલાયેલું ઉદાહરણ

પ્રશ્ન:

$3x + 1 < 10$ ને ઉકેલો અને સંખ્યા રેખા પર નિરૂપણ કરો.

ઉકેલના પગલાં:

  • $3x < 10 - 1 \implies 3x < 9$
  • $x < 3$
  • સંખ્યા રેખા પર (3, $\infty$) ના અંતરાલને દર્શાવો.

૫. ક્રમચય અને સંચય (Permutations & Combinations)

ક્રમચય એ પસંદગીના ક્રમનું મહત્વ દર્શાવે છે, જ્યારે સંચય માત્ર વસ્તુઓની પસંદગી પર ધ્યાન કેન્દ્રિત કરે છે.

મહત્વના સૂત્રો

ક્રમચય (Permutation): $${}_n P_r = \frac{n!}{(n-r)!}$$ સંચય (Combination): $${}_n C_r = \frac{n!}{r! (n-r)!}$$

૬. દ્વિપદી પ્રમેય (Binomial Theorem)

દ્વિપદી પ્રમેય કોઈપણ ધન પૂર્ણાંક ઘાત માટે $(a+b)^n$ નું વિસ્તરણ કરવાની રીત આપે છે. તેના સહગુણકો પાસ્કલના ત્રિકોણ દ્વારા મળે છે.

૭. સુરેખાઓ (Straight Lines)

યામ ભૂમિતિમાં, સુરેખાનું સમીકરણ એ બે ચલ x અને y માં એક ઘાતવાળું સમીકરણ હોય છે.

મહત્વના સૂત્રો

ઢાળનું સૂત્ર: $$m = \frac{y_2 - y_1}{x_2 - x_1}$$ અંત:ખંડ સ્વરૂપ: $$\frac{x}{a} + \frac{y}{b} = 1$$

૮. શંકુચ્છેદ (Conic Sections)

શંકુચ્છેદ એ શંકુ અને સમતલના છેદનથી મળતા આકારો (વર્તુળ, પરવલય, ઉપવલય, અતિવલય) છે.

૯. લિમિટ અને વિકલિત (Limits & Derivatives)

લિમિટ એ વિધેયના મૂલ્યનું અનુમાન છે જેમ જેમ ચલ કોઈ ચોક્કસ મૂલ્યની નજીક જાય છે. વિકલિત એ ફેરફારનો દર દર્શાવે છે.

મહત્વના સૂત્રો

વિકલિતની વ્યાખ્યા: $$\frac{d}{dx} f(x) = \lim_{h \to 0} \frac{f(x+h) - f(x)}{h}$$ ગુણાકારનો નિયમ: $$\frac{d}{dx} (u \cdot v) = u \frac{dv}{dx} + v \frac{du}{dx}$$
