ધોરણ 12 ગણિત સ્પેશિયલ ડિજિટલ નોટ્સ

ત્રિકોણમિતીય પ્રતિવિધેયો

ગુજરાત બોર્ડ અભ્યાસક્રમ આધારિત સરળ સમજૂતી, પ્રદેશ અને વિસ્તારના કોષ્ટકો, જીવંત આલેખો અને સૂત્રોનો અદભુત સંગ્રહ.

આલેખો જુઓ ગુણધર્મો વાંચો

પ્રતિવિધેય અને મર્યાદાઓ

મૂળભૂત વિભાવના અને વ્યાખ્યા

મુખ્ય વ્યાખ્યા

વિધેય \(f : A \rightarrow B\) એક-એક અને વ્યાપ્ત વિધેય હોય તો તે વ્યસ્ત સંપન્ન વિધેય છે. વિધેય \(f\) નું પ્રતિવિધેય અસ્તિત્વ ધરાવે છે.

જો \(y = f(x)\) હોય તો \(x = f^{-1}(y)\). જ્યાં \(f^{-1} : B \rightarrow A\) એ \(f\) નું પ્રતિવિધેય છે.

શાખા અને મર્યાદા

ત્રિકોણમિતીય વિધેયો તેમના કુદરતી પ્રદેશ પર એક-એક કે વ્યાપ્ત નથી. તેથી તેમના પ્રદેશ પર યોગ્ય મર્યાદા મૂકીને પ્રતિવિધેયો વ્યાખ્યાયિત કરાય છે.

મર્યાદિત પ્રદેશવાળી શાખાને 'મુખ્ય કિંમતવાળી શાખા' (Principal Value Branch) કહે છે.

ત્રિકોણમિતીય પ્રતિવિધેયોનાં પ્રદેશ અને વિસ્તાર (Table)

ક્રમ વિધેય પ્રદેશ (Domain) વિસ્તાર (મુખ્ય કિંમતવાળી શાખા)
1 \(y = \sin^{-1} x\) \([-1, 1]\) \(\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\)
2 \(y = \cos^{-1} x\) \([-1, 1]\) \([0, \pi]\)
3 \(y = \tan^{-1} x\) \(\mathbb{R}\) (અથવા \((-\infty, \infty)\)) \(\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)\)
4 \(y = \cot^{-1} x\) \(\mathbb{R}\) \((0, \pi)\)
5 \(y = \sec^{-1} x\) \(\mathbb{R} - (-1, 1)\) \([0, \pi] - \left\{\frac{\pi}{2}\right\}\)
6 \(y = \csc^{-1} x\) \(\mathbb{R} - (-1, 1)\) \(\left[-\frac{\pi}{2}, \frac{\pi}{2}\right] - \{0\}\)

પ્રતિવિધેયોનાં આલેખો (Graphs)

ઇન્ટરેક્ટિવ ગ્રાફ વિઝ્યુઅલાઈઝર

💡 મહત્વની નોંધ: કોઈ વિધેયનાં પ્રતિવિધેયનો આલેખ મૂળ વિધેયનાં આલેખના \(y = x\) રેખા પરના આરસી પ્રતિબિંબ (Mirror Image) સ્વરૂપે મળે છે. નીચે આપેલ ગ્રાફ ઇન્ટરેક્ટિવ છે!

મહત્વની નોંધ અને ઉદાહરણો

મુખ્ય કિંમત (Principal Value) મેળવવાની રીત

નોંધ (૧)

\(\sin^{-1} x\) અને \((\sin x)^{-1}\) બંને જુદા છે. \((\sin x)^{-1} = \frac{1}{\sin x}\). આ નિયમ તમામ ત્રિકોણમિતીય વિધેયો માટે લાગુ પડે છે.

નોંધ (૨)

જ્યારે પણ પ્રશ્નમાં પ્રતિવિધેયની શાખાનો ઉલ્લેખ ન હોય, ત્યારે તેની મુખ્ય કિંમતવાળી શાખા જ ધ્યાનમાં લેવાય છે.

નોંધ (૩)

પ્રતિવિધેયનું જે મૂલ્ય તેની મુખ્ય કિંમતવાળી શાખાના વિસ્તારમાં આવેલું હોય, તેને તે પ્રતિવિધેયની મુખ્ય કિંમત કહે છે.

✨ ઉદાહરણ ૧: \(\sin^{-1}\left(\frac{1}{\sqrt{2}}\right)\) ની મુખ્ય કિંમત શોધો.

• ધારો કે \(\sin^{-1}\left(\frac{1}{\sqrt{2}}\right) = y\). આથી \(\sin y = \frac{1}{\sqrt{2}}\).

• આપણે જાણીએ છીએ કે \(\sin^{-1}\) ની મુખ્ય કિંમતવાળી શાખાનો વિસ્તાર \(\left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\) છે.

• કારણ કે \(\sin\left(\frac{\pi}{4}\right) = \frac{1}{\sqrt{2}}\) અને \(\frac{\pi}{4} \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), તેથી મુખ્ય કિંમત \(\frac{\pi}{4}\) છે.

✨ ઉદાહરણ ૨: \(\cot^{-1}\left(-\frac{1}{\sqrt{3}}\right)\) ની મુખ્ય કિંમત શોધો.

• ધારો કે \(\cot^{-1}\left(-\frac{1}{\sqrt{3}}\right) = y\). તેથી \(\cot y = -\frac{1}{\sqrt{3}} = -\cot\left(\frac{\pi}{3}\right) = \cot\left(\pi - \frac{\pi}{3}\right) = \cot\left(\frac{2\pi}{3}\right)\).

• કારણ કે \(\cot^{-1}\) ની મુખ્ય કિંમતવાળી શાખા \((0, \pi)\) છે અને \(\frac{2\pi}{3} \in (0, \pi)\), તેથી મુખ્ય કિંમત \(\frac{2\pi}{3}\) છે.

મહત્વનાં ગુણધર્મો (Properties)

દાખલા ગણવા માટેના ઉપયોગી સૂત્રો

ગુણધર્મ : I (વ્યસ્ત અને વિપરીત સંબંધો)

  • 1. \(\sin^{-1}\left(\frac{1}{x}\right) = \csc^{-1} x, \text{ જ્યાં } x \ge 1 \text{ અથવા } x \le -1\)
  • 2. \(\cos^{-1}\left(\frac{1}{x}\right) = \sec^{-1} x, \text{ જ્યાં } x \ge 1 \text{ અથવા } x \le -1\)
  • 3. \(\tan^{-1}\left(\frac{1}{x}\right) = \cot^{-1} x, \text{ જ્યાં } x > 0\)

ગુણધર્મ : II (ઋણ ખૂણાના સૂત્રો)

  • 1. \(\sin^{-1}(-x) = -\sin^{-1} x, \text{ જ્યાં } x \in [-1, 1]\)
  • 2. \(\tan^{-1}(-x) = -\tan^{-1} x, \text{ જ્યાં } x \in \mathbb{R}\)
  • 3. \(\csc^{-1}(-x) = -\csc^{-1} x, \text{ જ્યાં } |x| \ge 1\)
  • 4. \(\cos^{-1}(-x) = \pi - \cos^{-1} x, \text{ જ્યાં } x \in [-1, 1]\)
  • 5. \(\sec^{-1}(-x) = \pi - \sec^{-1} x, \text{ જ્યાં } |x| \ge 1\)
  • 6. \(\cot^{-1}(-x) = \pi - \cot^{-1} x, \text{ જ્યાં } x \in \mathbb{R}\)

ગુણધર્મ : III (પરૂરક ખૂણાના સરવાળા)

  • 1. \(\sin^{-1} x + \cos^{-1} x = \frac{\pi}{2}, \text{ જ્યાં } x \in [-1, 1]\)
  • 2. \(\tan^{-1} x + \cot^{-1} x = \frac{\pi}{2}, \text{ જ્યાં } x \in \mathbb{R}\)
  • 3. \(\sec^{-1} x + \csc^{-1} x = \frac{\pi}{2}, \text{ જ્યાં } |x| \ge 1\)

ગુણધર્મ : IV (સરવાળા અને બાદબાકીના સૂત્રો)

  • 1. \(\tan^{-1} x + \tan^{-1} y = \tan^{-1}\left(\frac{x+y}{1-xy}\right), \text{ જ્યાં } xy < 1\)
  • 2. \(\tan^{-1} x - \tan^{-1} y = \tan^{-1}\left(\frac{x-y}{1+xy}\right), \text{ જ્યાં } xy > -1\)
  • 3. \(2\tan^{-1} x = \tan^{-1}\left(\frac{2x}{1-x^2}\right)\)
